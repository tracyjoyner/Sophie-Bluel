# Dynamic website using JavaScript - Sophie Bluel

# Scenario:
You work as a front-end developer for ArchiWebos, which has 50 employees. 

Having completed your last project slightly ahead of schedule, you are now sent to help out as a front-end developer for a team tasked with creating an online portfolio for an interior designer.

Your three main tasks. You’ll need to develop:
1 - the overview page presenting the interior designer’s work, (using the HTML code provided).
2 - the login page for the site administrator (the client), (needs to be coded from scratch).
3 - the modal window for uploading new media, (needs to be coded from scratch).


##Instructions to Run the Code

Start the backend from your terminal by following the instructions in the README file.

If you wish to view the backend and frontend code, open them in two separate instances of VSCode to avoid any issues.
